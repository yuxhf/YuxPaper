# 发布与研究边界

## 事实来源与权限

原工作区的项目注册表、Research Memory、claim ledger 与 evidence gate 保持权威。Human 拥有研究问题、实验与正式运行批准、标签和 ground truth、解释接受与论文 claim 的决定权。网站展示或生成配置不授权训练。

不自动修改 FP/TP 或 intent 标签，不隐藏失败与负结果，不把 idea 自动升级成论文结论。实验契约位于 `project/<Project>/03_experiments/researchbridge_specs/E###.md`，契约存在不代表实验获准。

## 公开导出规则

本仓库使用重新整理的框架文字与空白教学模板，不上传原论文 PDF、截图、附件数据库、真实阅读记录、实验结果或未发表稿件。模板中的记录均为空白或明确标注的虚构示例。

后续导出采用字段白名单，而非将整个工作目录推送到 GitHub。逐项检查个人信息、密钥、绝对路径、源论文版权与项目公开权限。论文关键图在个人知识库中的使用许可不自动延伸到公开站；公开展示需要重画并引用，或获得相应授权。

## 来源记录

`source-manifest.json` 只记录支持本框架的工作区相对路径、SHA-256、整理日期与说明，不复制原始私有内容。原工作区使用 `git_commit: not_available`。框架文档是摘要与结构设计，不声称本地每个历史文件都完全符合最新契约，也不替代全面数据审计。

正式实验的来源记录还应包含数据版本、精确命令、配置和代码哈希、时间、seed 与 approval reference。本次只构建文档和网站，没有正式实验。

## 教学模板

已有工作区应复用原文件，不能将 `templates/` 覆盖到正在使用的 claim ledger 或 registry。新用户可在空目录中按模板初始化，并调整本机路径。模板不授予执行实验、调度任务、调用付费 API 或重写 Zotero 数据库的权限。
